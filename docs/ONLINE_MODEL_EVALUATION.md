# 真实模型评测

## 当前状态

真实模型评测链路尚未随本仓库实现（`scripts/evaluate_online_model.py` 不存在），
以下内容保留为后续接入在线模型时的评测设计。当前没有任何可对外声明的线上模型结果，
项目不会用本地模型数据或估算 Token 冒充真实模型证据。

## 评测范围

评测固定使用本地 Embedding 和现有混合检索，只把答案生成切换为真实聊天模型，
从而隔离生成模型带来的质量、延迟、Token 和成本变化。

报告记录：

- 来源命中率、答案关键词召回和回答/拒答决策准确率；
- 端到端 P50/P95 与纯模型调用 P50/P95；
- 输入、输出、缓存输入、推理和总 Token；
- 总成本、平均每个请求成本、平均每次模型调用成本；
- 按问题类型和难度拆分的质量、延迟、Token 与成本；
- 模型名、提供方、价格日期和价格来源；
- 每条样本的回答、来源、用量和成本，便于人工复核。

不可回答且未通过证据门控的问题不会调用模型，其 Token 和成本记录为零。
如果模型提供方不返回可计费 Token 用量，评测会直接失败，不生成不完整成本报告。

## 执行方法

先使用有权执行评测的 API Key：

```dotenv
OPENAI_API_KEY=由执行人安全注入
CHAT_MODEL=要评测的模型名
OPENAI_BASE_URL=
```

价格必须在命令中显式提供，单位为“美元/百万 Token”，并记录价格日期和来源。
这样即使提供方以后调价，历史报告仍可复核：

```bash
uv run python scripts/evaluate_online_model.py \
  --input-price <输入价格> \
  --output-price <输出价格> \
  --cached-input-price <缓存输入价格> \
  --pricing-as-of <YYYY-MM-DD> \
  --pricing-source <官方价格页或内部计费说明> \
  --output reports/online_model_evaluation.json
```

兼容 OpenAI Chat Completions 的服务可通过 `OPENAI_BASE_URL` 和 `CHAT_MODEL`
切换，但价格仍需使用该服务自己的计费快照。

首次可先增加 `--limit 3` 做付费冒烟测试，确认返回 Token 用量后再运行完整 36 条数据集。
正式对比应使用完整数据集，不得将冒烟结果作为正式性能声明。

## 成本口径

```text
成本 =
  非缓存输入 Token × 输入单价
  + 缓存输入 Token × 缓存输入单价
  + 输出 Token × 输出单价
```

以上单价统一除以一百万。若没有单独提供缓存输入价格，则缓存输入按普通输入价格计算。
推理 Token 单独记录，但按主流接口约定已包含在输出 Token 内，不重复计费。

## 完成标准

只有同时满足以下条件，`docs/ROADMAP.md` 中的真实模型评测任务才能标记完成：

1. 在授权密钥环境运行完整 36 条数据集；
2. 报告中模型调用均返回非零 Token 用量；
3. 价格日期、来源和模型名完整；
4. 人工抽查回答与引用，没有明显越权或无依据内容；
5. 报告经过脱敏后作为 CI artifact 或受控评审证据保存。
